## Main project structure

- `client/src/App.tsx` and `client/src/pages/`: public homepage, shop, categories/products, About/Contact/FAQ/policies and explicitly guarded admin/login views.
- `client/src/components/`: shared brand header/footer, catalog cards, forms, SEO helper, loading/error/empty states and admin navigation.
- `client/src/lib/types.ts`: shared models plus one source of truth for official business identity/default contact and safe settings.
- `scripts/supabase-key-policy.mjs`: shared value-safe checks for publishable/anon keys and project URLs, imported by Vite, the browser client and the build-time catalog query.
- `scripts/site-origin-policy.mjs`: shared canonical-origin validation that rejects localhost/reserved domains and every configured Manus preview/internal host family.
- `client/src/lib/supabase.ts`: optional browser client using only the public project URL and publishable/anon key after the shared policy validates both.
- `scripts/site-origin-policy.mjs`: shared canonical-origin validator that blocks localhost/reserved addresses and all configured Manus preview/internal host families.
- `client/src/lib/data.ts`: typed, uncached published reads; allowlisted admin CRUD, category/settings operations and private-image upload/signed URL/cleanup.
- `client/src/lib/whatsapp.ts`: Nigerian phone normalization, international `wa.me` links, selected-option validation, branded product/contact/custom-order messages and safe link encoding.
- `client/src/lib/demo-data.ts`: centralized illustrative fallback catalog and styling assets; sample products and imagery are clearly labelled, replaceable and never claimed as genuine stock.
- `client/src/brand.css`: editorial palette/type/layout, responsive interaction states, visible keyboard focus, aspect-ratio image frames and reduced-motion support.
- `client/public/manus-routes.json` and `client/public/robots.txt`: registered public/private route map and crawler policy.
- `scripts/prerender.mjs`: build-time per-route HTML/metadata, plus optional Supabase public-RLS snapshot pages for visible categories and published products. It uses only public build keys, drops unsafe slugs, escapes injected content, sets known public routes indexable and retains a noindex fallback shell; no credentials enter embedded state.
- `supabase/migrations/`: versioned schema/RLS/Storage initialization and additive Mustaqeem identity/visibility migration.
- `README.md`, `.env.example`, `plan.md` and `TODO.md`: owner setup, credentials boundary, deployment/SEO constraints and outstanding work.

Owner pages include sign-in, overview counts from real database records, product CRUD/status/image management, categories and store settings. Admin reads/mutations require allowlist membership and are rechecked by RLS/Storage policies.

SEO uses route-specific initial HTML bodies/titles/descriptions, 3–8 natural relevant keywords, Open Graph/Twitter metadata and internal links for public routes. Canonical/absolute social/sitemap URLs are emitted only for a confirmed HTTPS `VITE_SITE_URL`; the shared origin guard rejects all configured Manus preview/internal hosts. The assigned `https://modest-8tfhztyx.manus.space` is configured for static output. The current public deployment still serves an older generic version pending publication. Some static hosts may send an arbitrary `/admin/products/:id/edit` URL to the indexable home shell before JavaScript runs; `robots.txt` disallows `/admin`, but host-level noindex/route behavior must be verified after publication and strengthened if needed. Real gateway redirects, trailing slashes, 404 status behavior and production response metadata remain unverified. Server-side rendering is not enabled because it is a one-way capability and the project remains static-first.

## Visual design

- **Design movement:** Contemporary Nigerian modest-fashion editorial with a quiet-luxury magazine sensibility rather than decorative thematic motifs.
- **Core principles:** Product-first presentation; calm, generous hierarchy; modest and culturally respectful styling; honest treatment of sample content and unknown policies.
- **Color philosophy:** Warm ivory and white for a welcoming canvas; sand as soft sectional contrast; mocha for readable text and confident actions; muted gold as a scarce finishing accent. Use ivory `#F6F0E7`, sand beige `#D8C4AD`, mocha brown `#594337`, muted gold `#B6975A`, dark text `#292522` and white `#FFFFFF`.
- **Layout paradigm:** Offset image-led split hero with text-safe space; generous editorial bands; asymmetric category introduction and aligned catalog views; practical responsive admin layouts using the same palette.
- **Signature elements:** Fine muted-gold editorial rules; small uppercase category/section labels with tracked lettering; large image crops framed by warm ivory margins.
- **Interaction philosophy:** Direct and reassuring, with accessible menus, touch-friendly actions, visible keyboard focus and explicit status/validation feedback; no hover-only controls.
- **Animation:** Restrained 160–220 ms affordance/menu transitions only; no parallax or attention-seeking entrances; disable nonessential motion for `prefers-reduced-motion`.
- **Typography:** Cormorant Garamond for display headings and DM Sans for navigation, catalog data, forms and body text; readable scale, strong contrast and comfortable line length.
- **Brand essence:** An editable premium Nigerian modest-fashion storefront, distinct through considered product presentation and direct WhatsApp conversations; refined, welcoming, trustworthy.
- **Brand voice:** Warm, composed and specific, not hype-driven. Examples: “Elegance in Every Layer.” and “Discover thoughtfully designed modest wear that brings together comfort, confidence, and timeless style.”
- **Wordmark and logo:** Set the full supplied business name in the editorial serif as a deliberate text wordmark, with a restrained gold rule; show a logo image only when the owner configures an approved HTTPS logo. Do not leave a generic “Your Brand” placeholder or invent a founder.
- **Signature brand color:** Mocha brown `#594337`, used for clear actions and wordmark rather than heavy page backgrounds.
